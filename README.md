# UV Eye Texture Studio v0.6

브라우저에서 VRM / VRChat / VTuber용 눈동자 UV를 비파괴 방식으로 디자인하는 React + TypeScript + Canvas 기반 도구입니다.

## v0.6 핵심 변화

- 동공 외곽 스트로크 제거: 동공은 색상 그라데이션과 음영만으로 형태가 보입니다.
- 완성형 눈 프리셋보다 **세부 요소 조합형 프리셋**을 대폭 확장했습니다.
- 양안 대칭 편집을 유지합니다.
- PNG의 비투명 영역을 기준으로 좌우 눈 UV 자동 인식을 지원합니다.
- 같은 프리셋을 다시 누르면 해제되며 모든 프리셋 그룹에 `끄기`가 있습니다.
- 모든 주요 장식 요소는 불투명도 및 위치/크기/회전 등을 수정할 수 있습니다.
- 사용자 PNG / WEBP / JPG 문양 이미지 오버레이를 지원합니다.
- 전체 UI는 한국어입니다.

## 포함된 프리셋

- 배경: 20종
- 홍채 외곽: 3종
- 동공: 15종
- 하단 포인트: 20종
- 상단 그림자: 15종
- 반사광: 20종
- 상징 문양: 15종
- 홍채 결/질감: 12종
- 내장 오버레이: 6종
- 손그림 질감: 5종

총 131개의 세부 프리셋을 조합할 수 있습니다.

## 실행

```bash

npm run dev
```

```bash

```

Cloudflare Pages:

## 기본 사용 순서

1. `UV 텍스처 열기`
2. 자동 인식된 양쪽 눈 마스크 확인
3. 필요하면 다각형/타원 마스크로 수정
4. 배경 프리셋 선택
5. 동공 프리셋 선택 후 위치·크기·색 조절
6. 하단 포인트 / 반사광 / 상단 그림자 / 상징 문양 / 홍채 결을 하나씩 추가
7. 필요하면 손그림 질감과 외부 문양 이미지를 추가
8. `전체 PNG 저장`

## 중요

- 처음 UV를 불러오면 모든 디자인 요소가 꺼진 클리어 상태입니다.
- 원본 UV의 캔버스 크기와 위치를 임의로 변경하지 않습니다.
- 디자인은 눈 마스크 내부에만 합성됩니다.
